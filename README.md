# Trésor

Application web (PWA) de **gestion de budget personnel**, gamifiée et privée.

Pensée pour reprendre le contrôle de ses finances sans connexion bancaire : tout en saisie manuelle, toutes les données restent **en local sur l'appareil** (`localStorage`).

## Fonctions (v1)
- **Dashboard** : solde actuel, budget du mois, derniers mouvements
- **Projection** : alerte court / moyen / long terme avant un découvert
- **Simulateur « Avant d'acheter »** : dis-moi un montant, je te dis si tu peux
- **Dettes** : centralise tes emprunts (à qui, combien, remboursé)
- **Gamification** : points, niveaux, séries (streaks), badges
- **PWA** : installable sur téléphone (écran d'accueil), fonctionne hors-ligne

## Confidentialité
Aucune donnée n'est envoyée sur internet. Tout vit dans le navigateur de l'appareil.
Export JSON disponible dans Profil → Réglages.

## Développement
Ouvrir `index.html` dans un navigateur.

## Déploiement
Prévu sur Vercel (site statique).
